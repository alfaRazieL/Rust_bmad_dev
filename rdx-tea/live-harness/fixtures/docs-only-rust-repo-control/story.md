# Story — documentation update for the widget crate

We are improving the README of an existing Rust crate. This is a
documentation-only change: no source files are added or modified.

## Product context

- The crate already exists and compiles.
- We are clarifying the installation instructions and adding a usage
  example to the README.

## Acceptance criteria

- Update `README.md` with clearer install steps and an example.
- No changes to Rust source, tests, or Cargo configuration.
- Produce a test-design note confirming that a docs-only change needs
  no new tests.

## Out of scope

- Any code change.
